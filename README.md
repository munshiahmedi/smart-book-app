# SmartBook App

A full-stack book management application built using React.js, Node.js, Express.js, and MySQL.

## Overview

SmartBook provides a web application for managing book records through a React frontend and a REST API backend.

## Technology Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **API Testing:** Postman
- **Version Control:** Git and GitHub

## Features

- Create, view, update, and delete book records.
- Manage book data through REST API endpoints.
- Store and retrieve records using MySQL.
- Validate incoming data on the backend.
- Organize backend code into routes, controllers, and service layers.

## Project Structure

The application contains separate frontend and backend components.

- `client/` — React frontend
- `server/` — Express backend and database integration

> Adjust these folder names to match your actual repository structure.

## Getting Started

1. Clone this repository.
2. Install dependencies in the frontend and backend directories.
3. Configure the MySQL database and environment variables.
4. Start the backend server.
5. Start the React frontend.

Refer to the relevant `package.json` files and environment configuration for the exact commands and required variables.

## Testing

API endpoints can be tested with Postman. Test successful CRUD operations and validation or database error responses.
